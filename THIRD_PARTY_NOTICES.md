# Third-party software

This repository contains and depends on third-party research code and
libraries. It includes modules derived from the OpenAI guided-diffusion and
guided-diffusion-style network stack used by the research workspace. Some
logger utilities also contain code adapted from OpenAI Baselines.

The repository also implements a small local 3D Haar `DWT_IDWT` helper so that
the released inference code can run without an external helper package.

The project does not yet include a project-level license or full upstream
license texts. Before public release, verify the exact license and attribution
requirements for each bundled file, especially code adapted from
guided-diffusion, MONAI, LPIPS, and any external baseline implementation or
pretrained model.
